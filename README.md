## 概要
Unity URP向けに制作したリアルタイムトゥーンシェーダーです。

3Dキャラクターのセル調陰影、アウトライン、リムライト、ハイライト、発光、空気遠近、カスタム法線による陰影制御を扱います。ポートフォリオで制作したキャラクターモデルをUnity上で意図したトゥーンルックに近づけるため、モデル制作、テクスチャ制作、シェーダー実装を一つの流れとして検証しました。
このリポジトリは、テクニカルアーティスト志望のポートフォリオ補足として公開しています。

## 制作背景
トゥーン調の3DキャラクターをUnity上で表示する場合、標準的なライティングだけでは意図した見た目になりにくい箇所が多くあります。
特に問題になった点は次の通りです。

```text
- 顔に不要な陰影が出る
- 髪や服の細かい凹凸によって影が割れすぎる
- 影境界を制御しないと、イラスト調の見た目になりにくい
- カスタム法線で陰影を滑らかにすると、実際の形状由来の情報が失われる
- アウトラインがカメラ距離やパースによって太く見えたり細く見えたりする
- リムライトが入る箇所に黒いアウトラインが残ると、ルックが重く見える
- 部位ごとにアウトラインの強さを調整したい
```

これらを解決するため、シェーダー内で陰影、輪郭線、マスク、カスタム法線、距離補正を組み合わせて制御しています。

## 主な機能

```text
- Base Color Mapによる基本色表示
- セル調の1影表現
- 影のしきい値調整
- 影境界のフェード調整
- Shadow Control Mapによる影の出方の制御
- Alpha Cutout
- Emissive表現
- Rimlight
- Highlight
- カメラ距離に応じた空気遠近
- カスタム法線による滑らかな陰影制御
- 実形状の法線を使った陰影補正
- 反転ハル方式のアウトライン
- 頂点カラーRチャンネルによるアウトライン幅制御
- 距離とパースを考慮したアウトライン補正
- 遠景でのアウトライン補正フェード
- ライト方向に応じたアウトライン抑制
```

## ファイル構成

```text
custom_shader_distr/
  ToonShader_distr.shader
```

### ToonShader_distr.shader

Unity URP用のトゥーンシェーダー本体です。

大きく分けて、以下の処理を担当します。

```text
1. アウトライン描画
2. 本体のトゥーンシェーディング
3. カスタム法線を使った陰影制御
4. マスクテクスチャによるルック調整
5. リムライト、ハイライト、エミッシブ、空気遠近の加算
```

## 想定環境

```text
Unity 6: URPプロジェクト
Render Pipeline: Universal Render Pipeline
Shader Language: ShaderLab / HLSL
Target: Realtime character rendering
```

このシェーダーはURP向けです。Built-in Render PipelineやHDRPでの使用は想定していません。

## 使用する主なデータ

このシェーダーでは、モデルやテクスチャ側に以下の情報を持たせることを想定しています。

```text
UV0:
  Base Color Mapや各種マスクを参照するための基本UV。

Vertex Color R:
  アウトライン幅の部位別制御に使用。

Mesh Normal:
  実形状の法線。アウトライン処理や、一部の陰影補正に使用。

Custom Normal:
  トゥーン陰影用の滑らかな法線。Blenderで作成し、UVチャンネル3に格納してUnity側で再構成する。

Base Color Map:
  キャラクターの基本色。

Shadow Control Map:
  影境界や影の出方を制御するためのマスク。

Opacity Map:
  Alpha Cutoutに使用。

Emissive Map:
  発光部分の制御に使用。

Rimlight Mask Map:
  リムライトを出す範囲の制御に使用。

Highlight Mask Map:
  ハイライトを出す範囲の制御に使用。

Facial Detail / Shape-based Mask:
  カスタム法線で失われやすい、実形状由来の細部陰影を補助するために使用。
```

## カスタム法線による陰影制御

### 目的

通常のメッシュ法線だけでトゥーン陰影を作ると、顔や髪、衣装の細かい形状に合わせて影が出てしまい、意図したイラスト調の見た目から外れることがあります。

そこで、シェーディング用に調整したカスタム法線を使用します。

### 法線の役割分担

```text
Mesh Normal:
  - 実際の形状を表す法線
  - アウトラインの押し出し方向
  - 形状由来の陰影補正
  - 一部のマスク処理

Custom Normal:
  - セル影の計算
  - ハーフランバート計算
  - 顔や髪の滑らかな陰影
  - ルック制御用の法線
```

このように法線の役割を分けることで、見た目の影は滑らかにしつつ、必要な箇所では実形状の情報も利用できます。

### UVへの格納

Blender側で作成したカスタム法線は、`mytoys_distr` の機能を使ってUVへ格納します。

考え方は次の通りです。

```text
customNormal.x, customNormal.y -> UV_A
customNormal.z                 -> UV_B
Unity Shader側                 -> UV_AとUV_Bを読み取り、float3として再構成
```

これにより、Unity側で通常のメッシュ法線とは別のシェーディング用法線を扱えるようにしています。

## セル調陰影

### 基本方針

陰影は、ライト方向と法線方向の関係をもとに計算します。ただし、通常の滑らかな陰影ではなく、しきい値を使って明部と影を分け、セル調の見た目に寄せています。

基本的な流れは次の通りです。

```text
1. カスタム法線とライト方向の内積を計算する
2. ハーフランバートに近い形で値を補正する
3. しきい値で明部と影を分ける
4. 境界のフェード幅を調整する
5. Shadow Control Mapで部位ごとに影境界を補正する
6. Base ColorとShadow Colorをブレンドする
```

### Shadow Control Map
Shadow Control Mapは、影の出方をUV単位で制御するために使用します。


## 実形状法線による陰影補正
カスタム法線を使うと、顔や髪の影を滑らかにできます。一方で、法線を滑らかにしすぎると、鼻、頬、目周り、衣装の段差など、実際の形状から得られるべき情報が弱くなります。

そのため、完全にカスタム法線だけで陰影を決めるのではなく、実形状の法線を使った補正も加えています。
この処理は、写実的な陰影を戻すためではなく、トゥーンルックとして必要な形状感だけを補うためのものです。

## リムライト
リムライトは、視線方向と法線方向の関係から計算します。
リムライトは、すべての部位に一律で入れると見た目が強くなりすぎます。そのため、マスクテクスチャを使って、出したい箇所と抑えたい箇所を制御できるようにしています。

## ハイライト
ハイライトは、髪、服、金属、装飾など、局所的に光沢を出したい箇所を想定しています。
ハイライトも、マスクテクスチャで出る範囲を制御します。パラメータだけで全体に入れるのではなく、テクスチャ側で部位ごとに調整できるようにすることで、キャラクタールックに合わせやすくしています。

## エミッシブ
エミッシブは、発光するパーツや演出的に明るく見せたい箇所に使用します。
Emissive Mapと強度パラメータを組み合わせて、発光範囲と明るさを調整します。

## 空気遠近
空気遠近は、カメラ距離に応じてキャラクターの色を背景色や指定色に近づける処理です。
遠景でキャラクターが背景から浮きすぎるのを防いだり、距離感を表現するのに使います。
キャラクター単体のプレビューでは目立ちにくい処理ですが、背景内に配置したときに見た目を整えるために入れています。

## アウトライン

### 基本方式

アウトラインは、背面法で描画しています。
実装が分かりやすくキャラクター全体に安定した輪郭を出しやすい一方で、カメラ距離やモデル形状によって線幅が変化しやすい問題があります。

### 頂点カラーRによるライン幅制御
アウトラインの太さは、頂点カラーのRチャンネルで部位ごとに調整できるようにしています。
これにより、以下のような調整ができます。

```text
- 顔の内側は線を弱くする
- 髪先は線を細くする
- 服や大きなシルエット部分は線を残す
- 小物や細かいパーツの線を抑える
```
アウトラインを一律に出すと、顔や細部が黒く潰れやすくなります。頂点カラーで制御することで、DCC側でアーティストが部位ごとに調整できます。

### 距離・パースを考慮したアウトライン補正
単純に法線方向へメッシュを押し出すだけでは、カメラ距離やパースによってアウトラインの見え方が変化します。

問題点は次の通りです。

```text
- 近距離では線が太く見える
- 遠距離では線が細くなりすぎる
- パースの影響で部位によって太さが揃わない
- 遠景で補正を効かせすぎると見た目が破綻する
```
そこで、クリップ空間のW値を使って、画面上での線幅ができるだけ一定に近づくよう補正しています。

ただし、遠距離でも同じ補正を強くかけ続けると、キャラクターが小さく表示される場面でアウトラインが不自然に目立つ場合があります。そのため、遠景では補正を徐々に弱める処理を入れています。
この設計により、近距離では線幅を安定させつつ、遠距離では見た目の破綻を抑えることを狙っています。

### リムライト部分のアウトライン抑制
リムライトが入る箇所に黒いアウトラインが強く残ると、明るい輪郭と黒い線が競合し、ルックが重く見えることがあります。
そのため、ライト方向やリムライトの出方に応じて、アウトラインを抑制する処理を入れています。

## 現在の制限
```text
- URP専用です。
- Built-in Render Pipeline / HDRPでは未検証です。
- メインライトを中心にしたルック調整を前提にしています。
- 複数ライト環境でのトゥーン表現は整理しきれていません。
- 汎用的なShaderGUIは未整備です。
- カスタム法線の作成とUV格納は、別途Blender側の作業が必要です。
- パラメータ名やコード構造には、整理の余地があります。
```
